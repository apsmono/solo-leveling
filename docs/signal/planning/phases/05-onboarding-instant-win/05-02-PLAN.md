## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/v1/onboarding/connect-app | App name crosses here (untrusted) |
| browser -> /api/v1/onboarding/digest | No user input, but triggers data queries |
| connect-app -> integration layer | OAuth flow triggered by app name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | connect-app app name injection | mitigate | Validate app name against hardcoded allowed list (gmail, youtube, notion, gdrive, github, telegram, discord); reject unknown names with 400 |
| T-05-06 | Information Disclosure | OAuth token leakage via connect-app | mitigate | connect-app endpoint only records app name in profile; actual OAuth tokens are managed by brain's integration clients, not stored in profile JSON (per RESEARCH.md Security Domain) |
| T-05-07 | Elevation of Privilege | Onboarding bypass after partial completion | mitigate | Backend profile check is authoritative; if profile exists with onboarding_step < 3, resume from last step; if profile complete, skip to Zen shell (D-08, D-09, D-10) |
| T-05-08 | Information Disclosure | Digest data exposure | accept | Digest queries connected sources for the authenticated owner only; single-owner model; all endpoints require auth |
| T-05-SC | Tampering | npm/pip installs | mitigate | No new packages required; existing dependencies only (lucide-react icons already imported) |
</threat_model>

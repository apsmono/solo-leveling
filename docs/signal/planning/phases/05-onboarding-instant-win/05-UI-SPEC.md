## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, wizard inner padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:**
- Identity Box textarea: minimum height **120px** (`min-h-[120px]`) for comfortable free-text entry
- App Connect button tap target: minimum **44px** height for touch usability
- Step indicator dots: **8px** diameter each with **12px** gap between dots

**Source:** CONTEXT.md D-07; Tailwind 8-point default scale.

## Component Inventory

Components to add or modify in this phase:

### 1. OnboardingWizard (new -- renders in Panel A)

Top-level container that replaces `ClarityBoard` content in Panel A during onboarding.

- **Layout:** Centered card, max-width **560px**, vertically centered in Panel A (`flex items-center justify-center min-h-[60vh]`)
- **Background:** Transparent (Panel A's `bg-bg` shows through)
- **Card style:** `bg-card border border-border rounded-xl p-6 lg:p-8 shadow-sm`
- **Step indicator:** Top of card, horizontal row of 3 dots + "Step N of 3" label right-aligned
  - Active dot: `w-3 h-3 rounded-full bg-accent`
  - Completed dot: `w-3 h-3 rounded-full bg-success`
  - Upcoming dot: `w-3 h-3 rounded-full bg-border`
  - Dots connected by a thin line (`h-px bg-border flex-1 mx-2`)
- **Step transitions:** `opacity-0 translate-y-2` to `opacity-100 translate-y-0` with `transition-all duration-300 ease-out`
- **State:** Lifted to `DashboardPage` level (same pattern as `guideMessages` state) -- `onboardingStep: 1 | 2 | 3`, `onboardingProfile: ProfileData | null`

### 2. IdentityBox (new -- Step 1 of wizard)

Free-text input for "what you do / what overwhelms you" (D-01, ONB-02).

- **Heading:** "Welcome to Signal" -- `text-xl font-semibold text-text mb-2`
- **Subheading:** "Tell me what you do and what overwhelms you. I'll set things up." -- `text-sm text-muted mb-6`
- **Textarea:**
  - Size: `w-full min-h-[120px] p-4 text-sm`
  - Style: `bg-input-bg border border-border rounded-lg text-text placeholder:text-muted/60 resize-none`
  - Focus: `focus:outline-none focus:ring-2 focus:ring-accent/50 focus:border-accent`
  - Placeholder: "I run a small design agency. Gmail is overwhelming, I get 100+ emails a day. I also follow a few YouTube channels for industry trends..."
- **Submit button:** "Continue" -- `Button variant="primary" size="lg" w-full mt-4`
  - Disabled until textarea has content (`disabled={text.trim().length === 0}`)
  - Loading state: spinner + "Analyzing..." during AI parsing
- **AI follow-up:** After initial submit, if AI needs more detail (D-01), render a secondary message below the textarea:
  - Style: `bg-surface border border-border rounded-lg p-4 text-sm text-text`
  - Icon: `Sparkles` Lucide icon (16px, `text-accent`) left-aligned
  - Example: "That's helpful -- could you also tell me which apps you spend the most time in?"
  - Textarea remains editable; user types follow-up and clicks "Continue" again

### 3. ProfileConfirmationCard (new -- Step 2 of wizard)

Displays AI-parsed profile as a confirmation card (D-02, D-03).

- **Card style:** Reuse StreamCard pattern -- `bg-card border border-border rounded-lg p-4`
- **Heading:** "Here's what I understood" -- `text-base font-semibold text-text mb-3`
- **Profile bullets:** Unordered list, each bullet is a parsed field:
  - Role: "You run a design agency"
  - Pain points: "Email overwhelm (100+ daily), staying current on industry trends"
  - Suggested apps: "Gmail, YouTube"
  - Style: `text-sm text-text space-y-2`, each bullet prefixed with `•` in `text-accent`
- **Edit button:** "Edit" -- `Button variant="ghost" size="sm"` positioned top-right of card
  - Clicking returns to Step 1 with the original text pre-filled
- **Confirm button:** "That looks right -- Continue" -- `Button variant="primary" size="lg" w-full mt-4`

### 4. AppConnectStep (new -- Step 2 continued / Step 2b)

After profile confirmation, shows relevant app connection cards (D-05, ONB-03).

- **Heading:** "Connect your apps" -- `text-base font-semibold text-text mb-1`
- **Subheading:** "I'll highlight the ones that matter most to you." -- `text-sm text-muted mb-4`
- **App cards:** 2-3 cards (only most relevant apps from profile), rendered as a vertical stack
  - Each card: `bg-card border border-border rounded-lg p-4 flex items-center gap-4`
  - App icon: 32x32px, Lucide icon (`Mail` for Gmail, `Youtube` for YouTube, `Rss` for news), color `--color-muted`
  - App name: `text-sm font-semibold text-text`
  - App description: `text-xs text-muted` -- e.g., "Your emails, compressed into signals"
  - Connect button: `Button variant="secondary" size="sm"` -- "Connect"
    - On click: triggers OAuth flow (brain's existing integration layer)
    - Loading: spinner + "Connecting..."
    - Connected: `Button variant="ghost" size="sm" disabled` -- checkmark icon + "Connected" in `text-success`
    - Error: `text-danger text-xs` below button -- "Connection failed. Try again."
- **Skip link:** "Skip for now" -- `text-sm text-muted hover:text-accent cursor-pointer mt-3 text-center w-full` (D-06)
- **Continue button:** Appears after at least one app is connected OR user clicks skip
  - "Continue" -- `Button variant="primary" size="lg" w-full mt-4`

### 5. InstantWinDigest (new -- Step 3 of wizard)

First live 24-hour mini-digest as the "Instant Win" (D-12, D-13, D-14, ONB-04).

- **Card style:** Reuse StreamCard pattern exactly -- `bg-card border border-border rounded-lg p-4`
- **Source label:** "Your first digest" with `Sparkles` icon (14px, `text-accent`) -- `text-xs text-muted flex items-center gap-1.5`
- **Time label:** "Last 24 hours" -- `text-xs text-muted`
- **Bullets:** Exactly 3 single-sentence bullets (D-12), same pattern as ContextNest stream cards
  - If connected data exists: real compressed summary from connected sources (D-14)
  - If no connected data (cold start): capability preview (D-13) -- "Here's what I'll do for you" with example bullets based on profile
  - Style: `text-sm text-text`, each bullet `• {sentence}`, `truncate` for overflow
- **Completion message:** Below the digest card
  - Icon: `CheckCircle` Lucide icon (20px, `text-success`)
  - Text: "You're all set. Signal is now watching your streams." -- `text-sm text-text` (D-15)
- **Get started button:** "Get started" -- `Button variant="primary" size="lg" w-full mt-4` (D-15)
  - On click: transitions to full Zen shell (sets `onboardingStep` to null, `zenView` to "core")
  - Animation: `opacity-0 scale-95` to `opacity-100 scale-1` with `transition-all duration-500 ease-out` for a satisfying "land"

### 6. OnboardingRouter (modification -- DashboardPage)

Logic gate that decides whether to render OnboardingWizard or ClarityBoard in Panel A.

- **Detection:** Backend profile check (D-08) -- `GET /api/v1/profile` returns 404 if no profile exists
- **State:** `onboardingState: "loading" | "onboarding" | "complete"` in DashboardPage
- **Loading:** Show spinner (same as existing auth loading spinner)
- **Onboarding:** Render `OnboardingWizard` in place of `ClarityBoard` in Panel A
- **Complete:** Render `ClarityBoard` as normal
- **Re-entry:** Skip straight to Zen shell on return visits (D-09) -- profile exists means onboarding complete
- **Interruption:** Resume from last completed step (D-10) -- backend tracks `onboarding_step` field

## Interaction States

| Component | State | Visual treatment |
|-----------|-------|-----------------|
| Step indicator dot (active) | current step | `bg-accent w-3 h-3 rounded-full` |
| Step indicator dot (completed) | done | `bg-success w-3 h-3 rounded-full` |
| Step indicator dot (upcoming) | future | `bg-border w-3 h-3 rounded-full` |
| Identity Box textarea (empty) | no input | Placeholder text in `text-muted/60`, submit button disabled |
| Identity Box textarea (focus) | typing | `ring-2 ring-accent/50 border-accent` |
| Identity Box textarea (filled) | ready | Submit button enabled, `bg-accent text-white` |
| AI follow-up message | parsing done | `bg-surface border-border` card with `Sparkles` icon |
| Profile card "Edit" button | hover | `text-accent` |
| App Connect card (idle) | not connected | `bg-card border-border`, "Connect" button in `variant="secondary"` |
| App Connect card (connecting) | OAuth in-flight | Spinner replaces button text, button disabled |
| App Connect card (connected) | success | Checkmark icon in `text-success`, "Connected" label, button disabled |
| App Connect card (error) | failed | `text-danger` error text below button, button remains clickable |
| Digest card (data available) | real data | Real bullets from connected sources |
| Digest card (cold start) | no data | Capability preview bullets, `Sparkles` icon header |
| "Get started" button | hover | `opacity-90` (standard primary button hover) |
| Wizard card entrance | mount | `opacity-0 translate-y-4` to `opacity-100 translate-y-0` |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Identity Box textarea labeled | `aria-label="Describe what you do and what overwhelms you"` |
| Step indicator announced | `aria-live="polite"` on step indicator container; screen reader announces "Step 2 of 3" on step change |
| App Connect buttons labeled | `aria-label="Connect {appName}"` on each Connect button |
| Connected state announced | `aria-live="polite"` on app card; announces "{appName} connected" on state change |
| Digest card readable | `role="article"` on digest card; bullets as `<ul><li>` |
| Keyboard navigation | All interactive elements are `<button>` or `<a>` -- native tab order |
| Focus management | On step change, focus moves to the new step heading (`tabIndex={-1}` + `focus()`) |
| Reduced motion | Existing `@media (prefers-reduced-motion: reduce)` in `globals.css` applies -- step transitions and card entrance animations respect this |

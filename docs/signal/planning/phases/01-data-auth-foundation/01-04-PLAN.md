## Key interfaces from RESEARCH.md

Pattern 4 (auth_session.py):
```python
from __future__ import annotations

import datetime
from typing import Any

from fastapi import APIRouter, HTTPException, Request, Response, status
from src.integrations.firebase.auth import verify_id_token, _init_firebase

router = APIRouter()
_SESSION_DURATION = datetime.timedelta(days=7)

@router.post("/auth/session-login")
async def session_login(payload: dict[str, Any], response: Response) -> dict[str, str]:
    id_token = payload.get("idToken", "")
    if not id_token:
        raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail="Missing idToken.")
    verify_id_token(id_token)
    _init_firebase()
    import firebase_admin.auth as fb_auth
    cookie = fb_auth.create_session_cookie(id_token, expires_in=_SESSION_DURATION)
    response.set_cookie(
        key="__session",
        value=cookie,
        max_age=int(_SESSION_DURATION.total_seconds()),
        httponly=True,
        secure=True,  # set False for local dev via env flag
        samesite="strict",
    )
    return {"status": "ok"}

@router.post("/auth/session-logout")
async def session_logout(response: Response) -> dict[str, str]:
    response.delete_cookie("__session")
    return {"status": "ok"}
```

## Threat mitigations
- httpOnly=True prevents XSS cookie theft
- Secure=True (configurable via env for local dev)
- SameSite=Strict prevents CSRF
- 7-day TTL via Firebase session cookie

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> FastAPI /auth/session-login | ID token crosses from browser to backend |
| FastAPI -> Firebase Admin SDK | Session cookie creation requires Admin SDK |
| Cookie -> Browser | Cookie stored in browser; must be httpOnly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-14 | Spoofing | Fake ID token | mitigate | verify_id_token validates Firebase signature and expiry |
| T-01-15 | Elevation of Privilege | XSS cookie theft | mitigate | httpOnly=True prevents JavaScript access to __session |
| T-01-16 | Spoofing | CSRF against session-login | mitigate | SameSite=Strict prevents cross-site cookie sending |
| T-01-17 | Information Disclosure | Cookie sent over HTTP | mitigate | Secure=True (configurable for local dev); cookie only sent over HTTPS |
| T-01-18 | Tampering | Session cookie manipulation | mitigate | Firebase session cookies are signed; tampering invalidates them |
</threat_model>

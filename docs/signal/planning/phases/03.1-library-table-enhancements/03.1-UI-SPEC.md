## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Cell padding, compact elements |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, expanded row inner padding |
| xl | 32px | Layout column gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level top/bottom padding |

**Exceptions:**
- Thumbnail column container: exactly **56×32px** (wider aspect ratio, `object-cover`) — from D-02
- Row checkbox column: **40px** fixed width — existing pattern in `TableView.tsx`
- ⋮ menu button tap target: minimum **32×32px** for usability

**Source:** CONTEXT.md D-02; Tailwind 8-point default scale.

## Typography

| Role | Size | Weight | Line Height | Font | Color |
|------|------|--------|-------------|------|-------|
| Body / row content | 14px | 400 (regular) | 1.5 | Outfit | `--color-muted` |
| Label / type badge | 12px | 400 (regular) | 1.4 | Outfit | `--color-muted` |
| Row title (truncated) | 14px | 400 (regular) | 1.4 | Outfit | `--color-text` |
| Expanded row heading | 16px | 600 (semibold) | 1.3 | Outfit | `--color-text` |
| Mono data (dates, IDs) | 12px | 400 (regular) | 1.4 | JetBrains Mono | `--color-muted` |

**Constraints:** Maximum 4 sizes (12, 14, 16, mono-12). Maximum 2 weights (400 regular, 600 semibold).

**Row title distinction:** Row title uses `text-text` (`--color-text`) while body/row content uses `text-muted` (`--color-muted`) — color contrast replaces the dropped 500 medium weight as the visual hierarchy signal.

**Source:** `globals.css` `body { line-height: 1.5 }`, existing TableView class `text-xs text-muted` for type badges.

## Color

| Role | Value (dark / light) | Usage |
|------|---------------------|-------|
| Dominant (60%) | `--color-bg` `#0c0c14` / `#f8fafc` | Page background, table background |
| Secondary (30%) | `--color-card` `#141420` / `#ffffff` | Table row background; `--color-surface` `#1c1c2e` for expanded row + menus |
| Accent (10%) | `--color-accent` `#55ffff` / `#0ea5e9` | See reserved list below |
| Destructive | `--color-danger` `#ff5555` / `#dc2626` | Delete action label + icon only |

**Accent reserved for:**
1. AI Summarize button label and border (in expanded row)
2. Thumbnail hover overlay ring (1px accent-colored outline on hover)
3. Focused / active table row left-border indicator (2px accent stripe)
4. Accordion expand chevron icon color (when row is open)

**Accent explicitly NOT used for:** ⋮ menu trigger button, date text, type badges, regular row hover backgrounds.

**Source:** `globals.css` `@theme` + `[data-theme="light"]` blocks.

## Component Inventory

Components to add or modify in this phase:

### 1. Thumbnail Cell (new — TableView)
- Container: `w-[56px] h-[32px]` flex-center, `rounded-sm overflow-hidden bg-surface`
- YouTube entries: `<img src={youtubeThumbnail(entry.source_url)} className="w-full h-full object-cover" onError={hideImgShowIcon} />`
- Non-YouTube / broken image: render `platformIcon(entry.source_url)` (Lucide icon, 20×20px, color `--color-muted`)
- Clickable: `<button onClick={openSourceUrlNewTab}>` wraps both img and icon fallback
- Hover: 1px `--color-accent` ring (`ring-1 ring-accent/60`)

### 2. ⋮ Overflow Menu (new — TableView row + CardView card)
- Trigger: `<button>` with `MoreHorizontal` Lucide icon (16px), `w-8 h-8` tap target, color `--color-muted` default → `--color-text` on hover
- Menu panel: `absolute right-0 z-50 w-40`, `bg-surface border border-border rounded-md shadow-lg`, `py-1`
- Menu items: 40px tall each, `px-3 text-sm`
  - "Open source URL" — `--color-text`, `ExternalLink` icon 14px left
  - "Delete entry" — `--color-danger`, `Trash2` icon 14px left
- Open/close: single `openMenuId: string | null` state at table level; click-outside closes via `useEffect` + `mousedown` listener
- CardView: menu positioned `absolute top-2 right-2`; hover-reveal via `group-hover:opacity-100 opacity-0 transition-opacity duration-150`
- No new library dependency — inline Tailwind + state only (from D-11)

### 3. Accordion Row Expand (new — TableView)
- Click target: row body (not thumbnail button, not ⋮ button, not checkbox)
- Expand state: `expandedRowId: string | null` local to `TableView`
- Collapsed → expanded: `max-h-0 overflow-hidden` → `max-h-[600px]` with `transition-[max-height] duration-200 ease-out`
- Expanded panel renders below the row, full table width (`colSpan={columns.length}`)
- Expanded panel background: `--color-surface` with `border-t border-border`
- Expand indicator: `ChevronDown` icon in last column (or title column), rotates 180° when open (`transition-transform duration-200`)
- One row open at a time — clicking another row closes current (D-17)
- Re-clicking same row closes it

### 4. Expanded Row Content
- Inner padding: `p-6` (24px all sides)
- Field layout: two-column grid `grid grid-cols-2 gap-4` on ≥768px, single column on mobile
- Fields shown (in order): title, summary, AI summary, tags, source URL, full content preview (max 400 chars, `line-clamp-4` overflow), captured_at
- Sections with no data: omit the field entirely (do not render empty labels)
- AI Summarize button:
  - Size: `px-4 py-2 text-sm`
  - Style: `border border-accent/60 text-accent rounded-md hover:bg-accent/10 transition-colors`
  - Loading state: replace label with spinner + "Summarizing…" (disable button during request)
  - On success: expanded panel rerenders with new AI summary; no toast needed
  - On error: `window.alert("Could not generate summary. Please try again.")`

### 5. Date Cell (update — TableView)
- Display: `Intl.DateTimeFormat(undefined, { day: 'numeric', month: 'short', year: 'numeric' }).format(new Date(entry.captured_at))` (from D-18)
- Sort: raw ISO accessor value (string comparison works for ISO 8601) — `sortingFn: 'datetime'` or default string sort on raw `captured_at`
- Hover tooltip: `title` attribute with relative time via local `relativeTime(date: Date): string` helper
  - Example output: "3 days ago", "just now", "2 months ago"
  - No external dependency; implement in `libraryHelpers.tsx`
- Font: `font-mono-data` class (already declared in `globals.css`)

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Thumbnail button keyboard accessible | `<button>` element (not `<div onClick>`) |
| ⋮ menu keyboard accessible | `role="menu"`, items `role="menuitem"`, `Escape` key closes menu |
| Row expand keyboard accessible | Row click target is `<tr tabIndex={0} onKeyDown enter/space>` |
| Chevron icon decorative | `aria-hidden="true"` on the chevron SVG |
| Relative date tooltip | `title` attribute (native browser tooltip) |
| Reduced motion | Existing `@media (prefers-reduced-motion: reduce)` in `globals.css` applies — no new keyframes needed |

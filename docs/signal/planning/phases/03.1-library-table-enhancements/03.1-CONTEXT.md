# Phase 3.1: Library Table Enhancements - Context

**Gathered:** 2026-05-30 (updated)
**Status:** Ready for planning

<domain>
## Phase Boundary

This phase closes UI/UX and data-layer gaps discovered after Phase 3 (Knowledge Library) shipped. It targets the **dashboard library table and card views** and the **brain's library API** — no new features beyond the listed scope, only correctness and usability improvements.

**In scope:**
- Add thumbnail column to TableView (56×32px, YouTube thumbnail or type icon fallback, clickable to open source URL)
- Add inline row expand to TableView (accordion — shows all entry fields + AI Summarize button)
- Add ⋮ action menu to TableView rows (Delete + Open source URL)
- Add ⋮ action menu to CardView cards (Delete + Open source URL, top-right corner, hover-reveal)
- Delete entry: backend DELETE endpoint + dashboard delete function; `window.confirm()` before delete; wait for API then remove row; `window.alert()` on error
- Fix date formatting in table's Date column: browser-locale format, sort by raw ISO value, tooltip with relative time on hover
- Audit and fix AI-summary endpoint base URL / path if misaligned
- Audit full data flow: `LibraryEntry` type fields, `_enrich_entry()` output, forward-compat fields for Phase 5/6
- Verify data format alignment with Phase 5 (Onboarding) and Phase 6 (Smart Feeds)

**Explicitly NOT in this phase:**
- New library features (sorting UI, bulk actions, filters) — Phase 5/6
- n8n integration — Phase 2 (separate track)
- Zen shell structural changes — Phase 4 (done)
- Multi-tenancy / per-user ownership (single-user brain — all authenticated users are "the owner")
- Soft-delete / entry recovery
- Full-page entry detail route (/library/:id)

</domain>

<decisions>
## Implementation Decisions

### Thumbnail Column (UPDATED)
- **D-01:** Column position: first content column (after checkbox column, before title)
- **D-02:** Container size: **56×32px** (wider video aspect ratio, `object-cover`)
- **D-03:** YouTube entries: use `youtubeThumbnail()` from `libraryHelpers.tsx`; non-YouTube: use `platformIcon()` type icon
- **D-04:** Clicking thumbnail/icon: **open source_url in a new tab** (same behavior as ⋮ menu "Open source URL")
- **D-05:** Broken image: `onError` hides the `<img>`, falls back to type icon

### Delete Capability (UPDATED — scope expanded to CardView)
- **D-06:** Trigger: **`window.confirm()`** before delete fires
- **D-07:** After successful delete: **wait for API 200, then remove row/card** from local state
- **D-08:** On API failure: **`window.alert()`** with error message
- **D-09:** TableView: trash action lives in a **⋮ overflow menu** (last column); menu also contains "Open source URL"
- **D-10:** CardView: **⋮ menu in top-right corner of each card** (hover-reveal); same two actions as table ⋮ menu
- **D-11:** ⋮ menu component: **simple inline component** — Tailwind + state, no new library dependency
- **D-12:** Ownership: **single-user brain** — all authenticated users can delete any entry; no `user_id` field needed
- **D-13:** Backend: `DELETE /api/v1/library/entries/{entry_id}` — **hard-delete** (physical removal from store)

### Inline Row Expand — TableView (NEW)
- **D-14:** Click on row body (not thumbnail, not ⋮ menu) → **accordion expand in-place** (no drawer, no navigation)
- **D-15:** Expanded content: **all available entry fields** — title, summary, AI summary (if present), tags, source URL, full content preview, captured_at
- **D-16:** Include an **AI Summarize button** in the expanded row — calls the `synthesizeEntry()` endpoint already in `api.ts`
- **D-17:** Only one row can be expanded at a time (clicking another row collapses the current one)

### Date Formatting (UPDATED)
- **D-18:** Format: **browser locale** via `Intl.DateTimeFormat` with `{ day: 'numeric', month: 'short', year: 'numeric' }` — adapts to user's locale
- **D-19:** Column sort: sort by **raw ISO `captured_at` value** (TanStack Table `sortingFn` receives raw accessor); display cell shows formatted string
- **D-20:** Hover tooltip: **relative time** (e.g., "3 days ago") via `title` attribute or lightweight Tailwind tooltip

### AI Summaries Endpoint Audit (unchanged from prior context)
- Current path: `POST /api/v1/library/entries/{entry_id}/synthesize`
- Current `API_BASE`: `import.meta.env.VITE_API_BASE || "https://api.apsmono.com"`
- Audit task: verify reachability against production brain; update `VITE_API_BASE` in `.env` / `.env.production` if misaligned; do NOT change endpoint contract

### Data Structure Audit (unchanged from prior context)
- `LibraryEntry` in `dashboard/src/types/index.ts` currently lacks: `thumbnail_url`, `image_url`, `og_image`, `ai_summary`, `summary`, `platform`
- Audit `_enrich_entry()` in `solo-leveling/src/api/library.py`
- Add optional forward-compat fields to `LibraryEntry` type now so Phase 5/6 doesn't need a type migration

### Claude's Discretion
- Exact accordion animation style for row expand
- Whether expanded row shows a "collapse" indicator or closes on re-click of same row
- ⋮ menu open/close behavior (click-outside to close)
- Whether to add `image_url` / `og_image` to `_enrich_entry()` now or defer to Phase 6

</decisions>

- `platformIcon(source_url?)` in `libraryHelpers.tsx` — returns Lucide ReactNode icon by type; use as fallback in thumbnail column and expanded row

- `synthesizeEntry(id)` in `api.ts` — already exists at line ~186; use in expanded row Summarize button

- TanStack Table `columnHelper.accessor("captured_at")` — already defined at line ~95; update cell renderer for formatted date

### Established Patterns
- All protected API routes use `require_auth` FastAPI dependency — DELETE endpoint must follow same pattern
- `_get_store()` pattern in `library.py` — use to get store instance in DELETE handler
- `_entry_id_from_path(path)` — existing helper; check if needed for DELETE or if `entry_id` is passed directly

- Row expand state: local to `TableView` (one `expandedRowId: string | null` state)

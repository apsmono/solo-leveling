    The method signature stays: `def delete_entry(self, entry_id: str) -> bool`

    Implementation logic:
    1. Call `index = self.load_index()` to get the current index
    2. Iterate over `index.get("entries", [])` — for each record, get `path = record.get("path", "")`
    3. Call `rec_id = self._entry_id_from_path(path)` to derive the entry ID
    4. If `rec_id == entry_id`:
       a. Build full path: `full_path = self._project_root / path`
       b. If `full_path.exists()`:
          - If `full_path.name == "index.md"` (bundle): `import shutil; shutil.rmtree(full_path.parent)` to remove the entire bundle directory
          - Else (single file): `full_path.unlink()` to remove just the file
       c. Call `self.build_index()` to refresh the index so subsequent reads reflect the change
       d. Return `True`
    5. If loop completes without finding entry_id: return `False`

    Do NOT add vector DB cleanup — that is deferred to Phase 5/6 (per research open question 1).
    Do NOT add Firestore cleanup — that is out of scope for this phase.
    Do NOT change the method signature or add new parameters.
    Do NOT modify any other method in the class.

    Function signature: `export function relativeTime(dateInput: string | Date): string`

    Implementation (per RESEARCH.md code example):
    1. Convert input to Date: `const date = typeof dateInput === 'string' ? new Date(dateInput) : dateInput;`
    2. Guard: `if (isNaN(date.getTime())) return '';`
    3. Calculate diff: `const diffMs = Date.now() - date.getTime(); const diffSec = Math.floor(diffMs / 1000);`
    4. Define units array (descending): year (31536000), month (2592000), week (604800), day (86400), hour (3600), minute (60)
    5. Loop units: for each, compute `value = Math.floor(diffSec / seconds)`. If value >= 1, return `new Intl.RelativeTimeFormat(undefined, { numeric: 'auto' }).format(-value, unit)`
    6. Fallback: return `'just now'`

    Do NOT add any imports — `Intl.RelativeTimeFormat` is browser-native.
    Do NOT modify any existing function in the file.

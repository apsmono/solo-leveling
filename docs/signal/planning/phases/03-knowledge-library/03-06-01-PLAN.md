## Sort Contract

The sort param values are MAPPED to backend fields:
- "newest" -> field: captured_at, order: desc
- "oldest" -> field: captured_at, order: asc
- "title_asc" -> field: title, order: asc
- "title_desc" -> field: title, order: desc
- "updated" -> field: updated_at, order: desc

The `order` query param (asc/desc) is a direct override when `sort` is a field name (e.g., "captured_at", "title", "updated_at"). When `sort` is a named shortcut ("newest", "oldest"), the SORT_FIELD_MAP defines both field and order.
</context>

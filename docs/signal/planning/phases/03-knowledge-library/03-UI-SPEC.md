## Spacing Scale

All values are multiples of 4. Matches existing Tailwind defaults already in use throughout the dashboard.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between small elements |
| sm | 8px | Compact element spacing, badge padding, pill gaps |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, card internal spacing |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks, modal padding |
| 3xl | 64px | Page-level spacing (not used in Phase 3) |

**Exceptions:**
- CommandBar input height: 40px (py-2 + text-sm = 36-40px, matches existing Input primitive)
- DistractionGate modal: max-w-md (448px), p-6 (24px) — matches `LinkCaptureModal` pattern
- AI Guide panel width: `w-80` (320px) on lg+ screens, hidden on smaller — matches `DashboardPage` existing responsive pattern
- Spark Card min-height: none enforced — content-driven, matches existing card pattern

## Typography

Font families and sizes match existing `globals.css` declarations. No new sizes introduced.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Outfit | All body text, input text, card descriptions |
| Label | 12px (text-xs) | 500 (medium) | 1.4 | Outfit | Form labels, badge text, filter pills, meta text |
| Heading | 16px (text-base) to 20px (text-lg) | 600 (semibold) | 1.3 | Outfit | Card titles, section headings, modal titles |
| Display | 24px (text-2xl) | 700 (bold) | 1.2 | Outfit | Page title ("Dashboard") |
| Data | 12px (0.75rem) | 400 | 1.4 | JetBrains Mono | Timestamps, metrics, entry counts, code-like labels |

**Weight restriction:** Only 400 (regular) and 600 (semibold) for body/heading. Bold (700) reserved for the single page title only.

## Color

All values from `globals.css` CSS variables. Dark theme is default; light theme adapts via `[data-theme="light"]`.

### Dark Theme (default)

| Role | Variable | Value | Usage |
|------|----------|-------|-------|
| Dominant (60%) | `--color-bg` | #0c0c14 | Page background, input backgrounds |
| Secondary (30%) | `--color-card` | #141420 | Cards, panels, modals |
| Surface | `--color-surface` | #1c1c2e | Secondary surfaces, filter pills, tag chips |
| Text | `--color-text` | #e8e8f0 | Primary text |
| Muted | `--color-muted` | #8888a0 | Secondary text, placeholders, timestamps |
| Accent (10%) | `--color-accent` | #55ffff (cyan) | See reserved-for list below |
| Border | `--color-border` | #2a2a40 | All borders |
| Input bg | `--color-input-bg` | #0c0c14 | Form input backgrounds |

### Light Theme

| Role | Variable | Value |
|------|----------|-------|
| Dominant (60%) | `--color-bg` | #f8fafc |
| Secondary (30%) | `--color-card` | #ffffff |
| Surface | `--color-surface` | #f1f5f9 |
| Text | `--color-text` | #0f172a |
| Muted | `--color-muted` | #64748b |
| Accent (10%) | `--color-accent` | #0ea5e9 (sky blue) |
| Border | `--color-border` | #cbd5e1 |

### Accent Reserved For (explicit list)

Accent color is reserved for these specific element types ONLY:

1. **Primary action buttons** — "Send", "Save", "Park", CTA buttons
2. **Active filter/section pills** — currently selected filter state
3. **AI Guide icon + status dot** — the sparkles icon and live indicator
4. **Focus rings** — `focus:ring-accent/50` on inputs
5. **Hover glow border** — `.hover-glow` hover state border color
6. **Active tab indicator** — current nav tab text color
7. **Link hover state** — text color on interactive link hover
8. **Badge "accent" variant** — section badges, status badges

Accent is NOT used for: body text, borders (default state), backgrounds, error states, success states.

### Semantic Colors

| Color | Variable | Dark | Light | Usage |
|-------|----------|------|-------|-------|
| Danger | `--color-danger` | #ff5555 | #dc2626 | Error banners, destructive buttons, delete actions |
| Success | `--color-success` | #55ff55 | #16a34a | "Saved" confirmations, online indicators |
| Warning | `--color-warning` | #ffff55 | #d97706 | Duplicate warnings, offline state |

## Copywriting Contract

All copy is in English. Consistent with existing dashboard tone: direct, calm, reassuring.

### Primary CTA Labels

| Component | CTA Label | Action |
|-----------|-----------|--------|
| CommandBar send | "Send" (icon only — `Send` lucide icon) | Submits natural language command to AI Guide |
| CommandBar park | "Park thought" (icon + label) | Opens DistractionGate modal |
| DistractionGate save | "Park this thought" | Saves stray thought to library as section="thought" |
| Conceptual Search | "Search" (implicit — Enter key) | Triggers vector/hybrid search |
| Save Link (existing) | "Save Link" | Opens LinkCaptureModal |

### Empty States

| Component | Heading | Body |
|-----------|---------|------|
| AI Guide chat thread | "What can I help with?" | "Type a command or question below. I can search your library, capture notes, or help you think through something." |
| Spark Cards (no entries) | "Your library is empty" | "Save your first link or note to see recent entries here." |
| Conceptual Search (no results) | "No matches found" | "Try a different query or switch to keyword search for exact matches." |
| DistractionGate | (no empty state — always shows input) | — |

### Error States

| Component | Copy | Pattern |
|-----------|------|---------|
| CommandBar (parse failure) | "I couldn't understand that. Try rephrasing or use a simpler command." | Inline below input, text-danger |
| Conceptual Search (API error) | "Search failed. Check your connection and try again." | Inline in results area, banner-error pattern |
| DistractionGate (save failure) | "Could not park this thought. Please try again." | Inline in modal, banner-error pattern |
| StatusBanner (fetch failure) | Silent fail — show last known metrics or hide banner | No error banner (non-critical surface) |
| Spark Cards (fetch failure) | Silent fail — show nothing, no error | Non-critical surface, no error display |
| AI Guide (command execution error) | "Something went wrong. The command could not be executed." | Chat bubble from AI with error styling |

### Destructive Actions

| Action | Confirmation | Pattern |
|--------|-------------|---------|
| Clear chat history | No confirmation — instant clear | Trash icon button in chat thread header (existing `EntryAIPanel` pattern) |
| Park thought overwrite | No overwrite — always creates new entry | No destructive action |
| Remove Spark Card | Not supported in Phase 3 | Read-only display |

**No destructive actions in Phase 3 require confirmation dialogs.** All destructive actions (clear chat) are low-stakes and recoverable.

## Component Contracts

### 1. AIGuidePanel (GUIDE-01)

**File:** `dashboard/src/components/guide/AIGuidePanel.tsx`
**Analog:** `EntryAIPanel.tsx` (chat thread + input pattern)

**Layout:**
```
┌──────────────────────────┐
│ StatusBanner             │  ← fixed top, metrics
├──────────────────────────┤
│                          │
│ Chat Thread              │  ← scrollable, flex-1
│ (messages area)          │
│                          │
├──────────────────────────┤
│ CommandBar               │  ← fixed bottom, input + park
├──────────────────────────┤
│ Suggested Actions        │  ← optional, context-aware
└──────────────────────────┘
```

**Container:** `flex flex-col h-full border-l border-border bg-surface`
- Width: `w-80` (320px), `hidden lg:block shrink-0`
- Height: fills parent (no fixed height — parent constrains)
- Rendered outside tab switcher in `DashboardPage` (prevents React unmount on tab change)

**Props:**
```typescript
interface AIGuidePanelProps {
  activeView?: string;  // "overview" | "library" | etc. — for suggested actions
}
```

**State:** Lifted to `DashboardPage` level or context provider. Chat history persisted in localStorage keyed by `"dashboard:guide:chat"`. Command input is ephemeral (resets on send).

**Loading:** Shimmer skeleton for StatusBanner metrics on initial load. Chat thread shows "Thinking..." with animated spinner during command execution.

### 2. CommandBar (GUIDE-02)

**File:** `dashboard/src/components/guide/CommandBar.tsx`
**Analog:** `CommandInput.tsx` (text input + send button)

**Layout:**
```
┌─────────────────────────────────────────┐
│ [input...........................] [🚀] [📌] │
└─────────────────────────────────────────┘
```

**Input:** `Input` primitive — `bg-input-bg border border-border rounded-lg px-3 py-2 text-sm`
- Placeholder: "Ask anything or type a command..."
- Debounce: 300ms before sending to backend (per CONTEXT.md)
- Enter key sends; Shift+Enter for newline (if textarea variant used)

**Send button:** `Button` variant="primary" size="sm" — accent bg, white text, `Send` icon
**Park button:** `Button` variant="ghost" size="sm" — `Lightbulb` icon + "Park thought" label

**Props:**
```typescript
interface CommandBarProps {
  onSend: (text: string) => void;
  onPark: () => void;
  loading?: boolean;
  disabled?: boolean;
}
```

**Behavior:**
- On send: clear input, call `onSend(text)`, show loading state
- On park: call `onPark()` (opens DistractionGate)
- Disabled state: grayed out while command is executing
- Loading state: `Loader2` spinner replaces `Send` icon

### 4. DistractionGate (GUIDE-05)

**File:** `dashboard/src/components/guide/DistractionGate.tsx`
**Analog:** `LinkCaptureModal.tsx` (modal + form + save pattern)

**Layout:**
```
┌─── Park a Distraction ─────────────┐
│                                     │
│  "What's on your mind?"             │
│  ┌─────────────────────────────┐    │
│  │ [textarea..............]    │    │
│  └─────────────────────────────┘    │
│                                     │
│  [Park this thought]      [Nevermind]│
└─────────────────────────────────────┘
```

**Modal:** Fixed overlay `bg-black/50`, centered card `max-w-md rounded-xl border border-border bg-card p-6 shadow-lg`
- Matches `LinkCaptureModal` overlay + card pattern exactly
- Title: "Park a Distraction" with `Lightbulb` icon in accent
- Body: Single textarea, `bg-input-bg border border-border rounded-lg`, rows=3
- Placeholder: "What's on your mind? I'll save it for later."

**Props:**
```typescript
interface DistractionGateProps {
  open: boolean;
  onClose: () => void;
  onSaved?: () => void;
}
```

**Behavior:**
- On save: POST to `/api/v1/guide/park` with text content. Backend saves as library entry with section="thought"
- Success: brief "Saved!" confirmation (800ms), then close
- Error: inline banner-error below textarea
- On close: reset textarea, clear error
- On open: focus textarea automatically

**Copy:**
- CTA: "Park this thought"
- Cancel: "Nevermind" (ghost button)
- Success: "Thought parked. Back to focus." (success badge)
- Error: "Could not park this thought. Please try again."

## Interaction Patterns

### Command Flow (CommandBar -> Backend -> Chat Thread)

```
User types command
    ↓
300ms debounce
    ↓
POST /api/v1/guide/command { text }
    ↓
Backend: LLM intent parsing → dispatch → response
    ↓
Response appears as AI message in chat thread
    ↓
If intent=library_search: results shown as clickable cards in chat
If intent=park_distraction: DistractionGate opens
If intent=status: StatusBanner refreshes
```

### Search Mode Switch

```
User clicks "Semantic" pill
    ↓
Search mode state changes to "vector"
    ↓
Placeholder text updates
    ↓
Next search triggers vector search endpoint
    ↓
Results show similarity scores
```

### Distraction Parking Flow

```
User clicks Park button in CommandBar
    ↓
DistractionGate modal opens
    ↓
Textarea auto-focused
    ↓
User types thought → clicks "Park this thought"
    ↓
POST /api/v1/guide/park { text }
    ↓
Backend saves as library entry (section="thought")
    ↓
"Thought parked. Back to focus." shown for 800ms
    ↓
Modal closes, focus returns to previous context
```

### Panel Toggle

```
User clicks panel toggle button in header
    ↓
LayoutProvider toggles guideVisible
    ↓
LocalStorage persisted
    ↓
AIGuidePanel slides in/out (CSS transition)
    ↓
Main content area reclaims/loses 320px
```

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Keyboard navigation | All interactive elements focusable. Tab order: StatusBanner (skip) -> Chat thread -> CommandBar input -> Send -> Park |
| Focus management | DistractionGate traps focus on open, restores on close. CommandBar input focused on panel mount |
| Screen reader | ARIA labels on icon-only buttons ("Send command", "Park a thought", "Toggle AI Guide"). Chat messages use `role="log"` |
| Reduced motion | All animations respect `prefers-reduced-motion: reduce` (already in globals.css) |
| Color contrast | All text/bg combinations meet WCAG AA (verified: accent #55ffff on bg #0c0c14 = 11.5:1; text #e8e8f0 on card #141420 = 12.1:1) |
| Touch targets | Minimum 44px for mobile. Buttons use `py-2` (8px*2 + text) = ~40px; add `min-h-[44px]` for mobile |

```
POST /api/v1/feeds/manage   — {action, url} -> {status, feeds[]}
```

Data contract note — backend `read` vs frontend `unread` boolean inversion:
The backend library store uses `read: true/false` in frontmatter (where `read: false` means unread/new).
The frontend StreamCardData uses `unread: boolean` (where `unread: true` means new).
The mapping is: `unread: entry.read === false`. This inversion MUST be applied in the `feedEntryToCard` mapper.

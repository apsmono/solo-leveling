## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:**
- Unread indicator dot: **8px** diameter (`w-2 h-2 rounded-full`)
- Reading-time metric badge: **24px** height (`h-6`) with **8px** horizontal padding
- Expandable sources chevron: **44px** minimum tap target (`min-h-[44px] min-w-[44px]`) for touch usability
- StreamCard max height remains **140px** (existing), expandable sources section adds **max 120px** when expanded

**Source:** Existing StreamCard pattern, Tailwind 8-point scale, Phase 05 UI-SPEC touch target precedent.

## Component Inventory

Components to add or modify in this phase:

### 1. StreamCardData type extension (modification)

Add optional fields to `dashboard/src/components/zen/types.ts`:

```typescript
export interface StreamCardData {
  id: string;
  source: string;
  timeLabel: string;
  bullets: [string, string, string];
  kind?: "email" | "news" | "library" | "generic" | "youtube";  // add "youtube"
  // --- Phase 6 additions ---
  sources?: { title: string; url: string }[];  // dedup expandable source list
  unread?: boolean;                              // silent queue indicator
  readingTime?: {                                // YouTube reading-time metric
    watchMinutes: number;
    readSeconds: number;
  };
}
```

**Source:** CONTEXT.md D-02 (reading metrics), D-09 (unread flag), D-13 (sources array).

### 2. StreamCard -- YouTube variant (modification)

Extend existing `StreamCard.tsx` to handle the `youtube` kind and new fields.

- **Kind icon:** Add `Youtube` from lucide-react to `kindIcon` map, colored `text-accent`
- **Reading-time metric:** Render below the source label row when `card.readingTime` exists
  - Format: `"{X} min watch -> {Y} sec read"` (D-02)
  - Style: `text-xs font-semibold text-accent font-mono` (reading-time metric typography row)
  - Placement: Right-aligned in the source label row, replacing `timeLabel` position
  - The `timeLabel` moves to a second line or is omitted when `readingTime` is present
- **Unread indicator (D-09):**
  - Left border: `border-l-2 border-accent` on the article element when `card.unread === true`
  - Dot indicator: `absolute -top-1 -right-1 w-2 h-2 rounded-full bg-accent` positioned on the card's top-right corner
  - Both indicators fade when the card is selected (the existing `selected` state)
- **Max height exception:** YouTube cards with reading-time metric may exceed the 140px max -- allow `max-h-[160px]` for YouTube kind

### 3. StreamCard -- Dedup sources expansion (modification)

Add expandable source list for news dedup cards (D-11).

- **Trigger:** Chevron-down icon (`ChevronDown` from lucide-react) rendered below the bullets when `card.sources` has 2+ items
  - Style: `text-xs text-muted flex items-center gap-1 cursor-pointer hover:text-accent min-h-[44px]` (touch target)
  - Text: "{N} sources" (e.g., "3 sources")
  - Chevron rotates 180deg when expanded (`transition-transform duration-200`)
- **Expanded panel:** Renders below the trigger
  - Style: `mt-2 pt-2 border-t border-border space-y-1`
  - Each source: `<a>` tag with `text-xs text-muted hover:text-accent truncate block`
  - Max 5 sources shown; if more, show "+{N} more" in `text-xs text-muted`
- **Collapse:** Click chevron again or click anywhere outside the card collapses the panel
- **Keyboard:** `Enter` or `Space` on chevron toggles expansion; `Escape` collapses

### 4. ContextNest -- Feed queue integration (modification)

Modify `ContextNest.tsx` to pull from feed queue in addition to library entries.

- **Data source:** Fetch from `/api/v1/feed/queue` (library entries with `read: false`) AND `/api/v1/library/recent` (existing)
- **Merge strategy:** Feed queue items appear first (sorted by newest), then library recent items, capped at 6 total
- **Unread section header:** When unread items exist, render a subtle count above the grid:
  - "{N} new" -- `text-xs font-semibold text-accent mb-2`
  - Fades away after 3 seconds or when user scrolls (non-intrusive, D-08/D-04)
- **Auto-mark as read:** When a card enters the viewport (IntersectionObserver, threshold 0.5), flip `read: true` via `PATCH /api/v1/library/entries/{id}` with `{ read: true }` (D-10)
  - The unread indicator fades out with `transition-opacity duration-500`

### 5. CommandBar -- Feed command detection (modification)

Extend `CommandBar.tsx` intent handling for RSS feed management (D-07).

- **No visual changes to CommandBar itself** -- the existing input, submit, and park-a-thought UI remain unchanged
- **Guide response patterns:** When the CommandBar sends a feed-related command, the AI Guide (Panel B) responds with:
  - Feed added: `StreamCard` with `kind: "news"`, source: "Feed Manager", bullets: ["Added {feedName} to your feeds.", "New items will appear in your Context Nest.", "You'll see them next time you open Signal."]
  - Feed removed: Similar card, bullets: ["Removed {feedName} from your feeds.", "Existing cards from this source will remain in your library."]
  - Invalid feed URL: Error card, `kind: "generic"`, bullets: ["Could not add that feed.", "Please check the URL and try again.", "Example: add feed: https://techcrunch.com/feed"]
- **Card styling:** Reuses existing StreamCard pattern -- no new component needed

### 6. FeedQueueEmptyState (new -- rendered in ContextNest when no feeds)

Shown when the ContextNest has no feed items and no library items (rare, first-run after onboarding without feeds configured).

- **Style:** `text-center py-8`
- **Icon:** `Rss` from lucide-react, 32px, `text-muted`
- **Heading:** "No feeds yet" -- `text-base font-semibold text-text mb-2`
- **Body:** "Paste a YouTube link or add an RSS feed via the Command Bar to get started." -- `text-sm text-muted`
- **No CTA button** -- the Command Bar is always visible in Panel B

## Interaction States

| Component | State | Visual treatment |
|-----------|-------|-----------------|
| StreamCard (unread, new) | `unread === true` | `border-l-2 border-accent` + dot indicator top-right |
| StreamCard (read) | `unread === false` | Standard `border-border` (existing) |
| StreamCard (YouTube, idle) | kind youtube, no selection | Youtube icon in `text-accent`, reading-time metric below source |
| StreamCard (YouTube, selected) | kind youtube, selected | `border-accent ring-1 ring-accent/30` (existing selection pattern) |
| Dedup sources (collapsed) | `sources` present, not expanded | Chevron-down icon + "{N} sources" text |
| Dedup sources (expanded) | clicked chevron | Chevron rotates 180deg, source list renders below |
| Dedup sources (hover) | hovering source link | `text-accent` color change |
| ContextNest unread count | unread items present | "{N} new" in `text-xs font-semibold text-accent` |
| ContextNest unread count (fade) | 3s elapsed or scroll | `opacity-0 transition-opacity duration-1000` |
| Feed add response (Guide) | Command "add feed: ..." | StreamCard with kind "news", success bullets |
| Feed remove response (Guide) | Command "remove feed: ..." | StreamCard with kind "news", confirmation bullets |
| Feed error response (Guide) | Invalid URL | StreamCard with kind "generic", error bullets |
| Empty Context Nest | no feeds, no library | Rss icon + "No feeds yet" message |
| Reading-time metric | hover | No change (static display) |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Dedup sources toggle labeled | `aria-label="Show {N} sources"` / `aria-label="Hide sources"` on chevron button |
| Dedup sources panel announced | `aria-expanded` attribute on chevron button; `role="region"` on expanded panel |

| Keyboard navigation | Dedup chevron is a `<button>`; source links are `<a>` tags -- native tab order |
| Focus management | No focus traps -- all new interactive elements follow existing tab order |
| Reduced motion | Existing `@media (prefers-reduced-motion: reduce)` in `globals.css` applies -- chevron rotation and unread fade respect this |

## Integration Points

### Backend (brain)

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/v1/feed/youtube` | POST | Compress YouTube URL to 3-bullet card (reuses `fetch_transcript()` + LLM compression) |
| `/api/v1/feed/queue` | GET | Fetch library entries with `read: false` for silent queue |
| `/api/v1/library/entries/{id}` | PATCH | Mark entry as read (`{ read: true }`) when card enters viewport |
| `/api/v1/feed/rss` | POST | Add RSS feed URL to profile config |
| `/api/v1/feed/rss` | DELETE | Remove RSS feed URL from profile config |
| `/api/v1/feed/rss/refresh` | POST | Trigger immediate RSS poll (for testing; normally n8n scheduled) |

### Frontend (dashboard)

| Component | Modification |
|-----------|-------------|
| `types.ts` | Extend `StreamCardData` with `sources?`, `unread?`, `readingTime?`; add `"youtube"` to kind union |
| `StreamCard.tsx` | Add YouTube kind icon, reading-time metric, unread indicator, dedup sources expansion |
| `ContextNest.tsx` | Fetch from feed queue, merge with library recent, unread count header, auto-mark-as-read via IntersectionObserver |
| `CommandBar.tsx` | No visual changes -- intent parsing handles feed commands; Guide responses render as StreamCards |
| `globals.css` | No changes -- all new styles use existing tokens and Tailwind utilities |

### n8n templates

| Template | Purpose |
|----------|---------|
| `rss_feed_poll.json` | New n8n workflow template: polls configured RSS feeds, compresses to 3-bullet cards, pushes to brain |
| `gmail_read_summary.json` (existing) | Reuse pattern for email compression pipeline |

<objective>
Build the backend feed compression engine: a new `feeds.py` module with `compress_youtube()`, `compress_news()`, and `compress_email()` functions following the `generate_digest()` LLM compression pattern; REST endpoints for YouTube compression, email compression, RSS ingestion, feed queue, and feed URL management; library store extension with a `read` flag for silent queue tracking; news dedup via vector cosine similarity; Command Bar intent wiring for YouTube URL detection and RSS feed management commands; and the n8n RSS polling workflow template.

Purpose: This is the backend half of Smart Feeds. It produces 3-bullet cards from YouTube, email, and RSS sources and stores them in the library with unread flags. The Command Bar intent parser is extended so the owner can paste YouTube URLs or type "add feed:" / "remove feed:" commands. The frontend plan (06-02) renders these cards in the Context Nest.

Output: `feeds.py`, `api/feeds.py`, `rss_poll_compress.json`, extended `library_store.py` with `read` field, extended `onboarding.py` with youtube/rss fetchers, extended `intent_parser.py` and `router.py` with youtube_compress and feed_manage intents, `test_feeds.py`, updated `CHANGELOG.md`.

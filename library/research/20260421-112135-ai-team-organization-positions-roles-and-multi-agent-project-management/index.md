## Summary

Framework for how multiple AI agents work together as a company team, with defined roles, task allocation patterns, coordination protocols, and PM-style orchestration.

## Why This Is Valuable

As AI projects scale, coordinating multiple specialized AI agents becomes critical. This captures proven patterns for effective AI teamwork, role clarity, async collaboration, handoff protocols, and scalability.

## Key Facts

- AI teams need 5 core roles: Strategic Planner (vision), Executor (implementation), Coordinator (routing), Reviewer (quality), Domain Expert (specialization)
- Work allocation by specialization, phase, risk level, and complexity ensures optimal matching
- Multiple AIs coordinate async via handoff summaries with clear ownership and pending state
- Git and persistent documentation form the coordination layer for distributed AI work
- Project Manager AI breaks work into tasks, assigns to right specialization, tracks progress, facilitates, resolves blockers
- Scaling from 1 to N AIs requires increasing structure

## Research Notes

- Human project management practices translate directly to AI teams: roles, ownership, handoffs
- AIs lack persistent memory across sessions, requiring document-based coordination
- Async coordination allows AIs to work independently without blocking each other
- Git becomes the source of truth for both code and coordination state
- Role specialization emerges naturally: reasoning AIs → planning, code AIs → execution
- Conflict resolution needs clear escalation: voting, PM arbitration, human judgment
